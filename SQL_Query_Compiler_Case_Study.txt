01Abstract
Modern database systems process SQL queries through several stages that are very similar to
the phases of a compiler. The main objective of this project is to design and implement a SQL
Query  Compiler  that  converts  SQL  queries  into  optimized  execution  plans  for  efficient
processing.
The  system  accepts  SQL  queries  containing  common  clauses  such  as  SELECT,  FROM,
WHERE, AND, OR, and ORDER BY. When a query is entered, the lexical analyzer scans the
input  and  breaks  it  into  meaningful  tokens  such  as  keywords,  identifiers,  operators,  and
constants. These tokens are then passed to the parser, which checks whether the query follows
the correct SQL grammar and generates a parse tree representing its structure.
After successful parsing, the semantic analyzer validates the query by checking the correctness
of table names, column names, and other references. It ensures that the query is meaningful
and can be executed without semantic errors. Once the query is validated, it is transformed into
a relational algebra representation, which serves as the intermediate representation of the query.
The  next  stage  focuses  on  optimization.  Query  optimization  techniques  such  as  predicate
pushdown and projection pushdown are applied to reduce unnecessary operations and improve
execution efficiency. These optimizations help minimize the amount of data processed and lead
to faster query execution. Based on the optimized representation, the system generates an
optimized query plan that can be used by a database engine for execution.
Through this project, students can understand how fundamental compiler concepts such as
lexical analysis, syntax analysis, semantic checking, intermediate representation generation,
and optimization are applied in real-world database systems. The project demonstrates the
strong relationship between compiler design and database query processing while providing
practical experience in implementing different phases of a compiler-based system.

03Proposed Article
Base Paper
Title Low-Latency Query Compilation
Authors Henning Funke, Jan Mühlig, Jens Teubner
Published inThe VLDB Journal, 2022
Relevance to the Project
The paper explains how SQL queries can be converted into efficient execution plans using a
query compilation process. It describes different stages such as query analysis, intermediate
representation generation, and query optimization before execution.
These ideas are similar to the objectives of this project, where SQL queries pass through stages
such as lexical analysis, parsing, semantic checking, intermediate representation generation,
and optimization.
Inspired by this approach, the proposed SQL Query Compiler transforms SQL queries into
relational algebra representations and applies optimization techniques to produce more efficient
query execution plans.
The output is a Validated Query.◦ 
Intermediate Representation (IR) Generator
The validated query is converted into a Relational Algebra Tree, which serves as the
intermediate representation of the query.
This representation is easier to analyze and optimize.

Query Optimizer
The optimizer applies optimization techniques such as Predicate Pushdown (filtering
unwanted rows as early as possible) and Projection Pushdown (selecting only the required
columns as early as possible).
These optimizations reduce unnecessary operations and improve query execution efficiency.

04Novelty
Most compiler design projects focus on programming languages and code generation. This
project is different because it applies compiler concepts to SQL query processing in a database
environment. The key features of the project are:
This project helps bridge the concepts of Compiler Design and Database Systems by showing
how SQL queries can be analyzed, represented, and optimized using compiler techniques.
Applying compiler phases such as lexical analysis, parsing, semantic checking, intermediate
representation generation, and optimization to SQL queries.
